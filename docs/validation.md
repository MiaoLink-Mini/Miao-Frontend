## 手工完整验收矩阵（模拟器检查不替代真机）

| 场景 | 操作与预期 |
| --- | --- |
| 原生编译 | 导入根目录，以实际开发者工具和 AppID 编译；记录基础库与工具版本 |
| 首次进入 | 进入演示工作台，四个 tab 切换正确；设备与待办数量一致 |
| 配对 | 输入 `WEAGENT-DEMO`，先看确认页；取消不绑定，过期不可确认 |
| 创建 | 设备→项目→Agent→中文多行输入→创建；双击只有一个逻辑会话 |
| 设备失效 | 创建页选中设备离线后保持原目标，并禁用创建；不得自动选其他主机 |
| 时间线 | 流式文本更新同一条消息，工具可展开／复制，Diff 显示版本与来源 |
| 阅览历史 | 手指开始浏览后不抢滚动位置，点击“回到最新消息”恢复跟随 |
| 键盘 | iOS／Android、多行中文输入法、横竖屏与安全区域下提交按钮可见 |
| 审批 | 待处理→审批，核对设备／项目／动作；显示接收／送达／确认，终态不可重选 |
| 回答 | 独立问题表单，必填校验，不将回答追加成普通 Prompt |
| 停止 | 点击停止本轮先等待回执；确认取消不声称撤回文件修改 |
| 弱网 | 我的→诊断→模拟断线；返回会话看最后已知状态，恢复后历史完整且无重复 |
| 撤销 | 撤销设备后旧会话不能继续显示正文或发送；需要新配对才能重新访问 |
| 缓存 | 清除本地正文后重新查看会话，应从完整基线重建，而不是只取旧游标之后 |
| 真实联调 | 接入确认 schema 和实际 Agent 版本后，逐项填写需求验收；演示测试不可替代 |
